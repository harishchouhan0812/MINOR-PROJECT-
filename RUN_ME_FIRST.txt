📋 STEP 1: INSTALL DEPENDENCIES
--------------------------------
Open terminal/command prompt in the edupulse-ai folder and run:

    npm install

⏱️ This will take 2-3 minutes. Wait for it to complete.


🚀 STEP 2: START THE APPLICATION
---------------------------------
After installation completes, run:

    npm run dev

✅ You'll see: "VITE v8.x.x ready in XXX ms"
✅ URL will be shown: http://localhost:5173/


🌐 STEP 3: OPEN IN BROWSER
---------------------------
Open your web browser and go to:

    http://localhost:5173/

You should see the EduPulse AI landing page with 5 role cards.


🎭 STEP 4: EXPLORE THE APPLICATION
-----------------------------------
Click on any role card to explore:

    🎓 Student Portal    - View grades and attendance
    👨‍🏫 Faculty Portal    - Monitor students and predictions  
    🤝 Mentor Portal     - Manage support cases
    💼 HOD Portal        - Department analytics
    🛡️  Admin Portal      - System management


📄 CONVERT DOCUMENTATION TO PDF
--------------------------------
To create PDF versions of all documentation:

Windows: Double-click this file in File Explorer:
    convert-to-pdf.bat

PowerShell:
    .\convert-to-pdf.ps1

Requirements:
    - Pandoc must be installed: https://pandoc.org/installing.html
    - Or use browser: Open .md file → Print → Save as PDF

PDFs will be created in the "docs-pdf" folder.

🆘 TROUBLESHOOTING
------------------
Port Already in Use:
    netstat -ano | findstr :5173
    taskkill /PID <PID_NUMBER> /F
    npm run dev

Page is Blank:
    Press Ctrl + Shift + R (hard refresh)
    Press F12 to check browser console for errors

Dependencies Won't Install:
    npm cache clean --force
    rm -r -force node_modules
    npm install

Application Not Working:
    1. Stop server: Ctrl + C
    2. Restart: npm run dev
    3. Hard refresh browser: Ctrl + Shift + R
